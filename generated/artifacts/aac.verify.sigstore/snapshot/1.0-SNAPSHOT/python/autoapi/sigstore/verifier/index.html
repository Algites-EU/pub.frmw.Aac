Bases: algites.lib.aac.coreintf.verification.AIiPackageVerifier

Verify an artifact using the official sigstore Python CLI module.

The signature proves artifact integrity; the supplied trust policy determines which signer/publisher identity is accepted. The verifier never falls back to “any valid signer”.

class sigstore.verifier.AIcSigstoreEntitlementEvidenceVerifier(policies: dict[str, AIcSigstoreTrustPolicy], *, runner: Callable[[Sequence[str]], subprocess.CompletedProcess[str]] | None = None)¶

Detached Sigstore verifier for entitlement-document files.

The configured policy is selected by the document issuer id. Core separately applies its trusted-issuer/component policy, so a cryptographically valid but unauthorized signer does not become a trusted license issuer merely by being validly signed.
