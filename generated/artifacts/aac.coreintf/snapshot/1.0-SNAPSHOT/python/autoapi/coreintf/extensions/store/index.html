class coreintf.extensions.store.AIiEntityExtensionDataStore¶

Bases: abc.ABC

Persistence-domain contract for component-extension data.

Component-owned extension payloads remain independent from persistence metadata. The store wraps each payload envelope in a revisioned record and exposes compare-and-swap mutation semantics.
