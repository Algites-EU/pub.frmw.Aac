class coreintf.runtime.provider.AIiProviderRuntime¶

Bases: abc.ABC

Explicit AAC provider runtime marker with per-instance lifecycle callbacks.

Capability operations are supplied by concrete provider-specific interfaces/classes. The lifecycle methods have no-op defaults, equivalent to default methods in a Java interface, so a provider overrides only the phases it needs.
