class python.eu.algites.frmw.aac.codegen.aic_general_defs_inline_dto_adapter.AIcGeneralDefsInlineDtoAdapter¶

Adapt registered AAC JSON definitions to the shared defs-codegen model and backend.

AAC capability bindings are emitted as one combined Python source unit, while the shared defs-codegen backend normally emits one standalone module per canonical definition. This adapter keeps schema normalization, naming, documentation, provenance, and DTO rendering in pub.tool.General and extracts only the generated declaration needed by the AAC binding.
