validate_resolved_configuration(resource_name: str, value: Mapping[str, object] | None) → tuple[str, Ellipsis]¶

Validate a resolved runtime configuration without treating top-level required as availability.

AAC multi-provider resolution may legitimately yield missing/UNDEFINED top-level values. required remains meaningful inside concrete nested structures that are present, but runtime availability/readiness is not inferred from top-level JSON Schema requiredness.
