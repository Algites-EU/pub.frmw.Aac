Persistent AAC process Runtime: exactly one child process per provider instance.

Core owns the Popen handle, process lifetime and json-lines IPC channel. Provider configuration and module state are therefore naturally instance-local. Requests are serialized per instance; nested calls to already resolved consumed capabilities travel back to Core using core_invoke frames and are safe because the resolved instance graph is acyclic.
