class coreimpl.entitlement_requests.AIcEntitlementIssuingRequestService¶

Generate and track request identities used to correlate returned entitlements.

This is deliberately not an anti-cloning DRM mechanism. The request id/digest binds a returned entitlement to an exact request; issuer signature/trust still establishes that the granted rights were issued by an authorized vendor.
