Reference read-only entitlement provider backed by signed entitlement files.

Files are discovered by glob; the detached verification sidecar is intentionally not interpreted here. Its path is exposed in verification_material so an evidence verifier such as the Sigstore plugin can validate the exact entitlement bytes.
